# Praktikum 5 - JavaScript Dasar

## Deskripsi
Praktikum ini bertujuan untuk mempelajari dasar-dasar JavaScript dan manipulasi elemen HTML (DOM), meliputi output, variabel, function, percabangan, form, dan validasi input.

## Teknologi
- HTML5
- JavaScript
- Visual Studio Code
- Web Browser

## Struktur Folder
- `index.html` - Halaman utama praktikum.
- `script.js` - Kode JavaScript untuk latihan.
- `mini-project.html` - Halaman kalkulator nilai mahasiswa.
- `mini-project.js` - Logika perhitungan nilai mahasiswa.

## Langkah Kerja dan Hasil

### Latihan 1 - Menampilkan Output
Menampilkan teks Hello World pada halaman HTML dan Console.

### Latihan 2 - Alert dan Prompt
Meminta nama pengguna dan menampilkan pesan sapaan.

### Latihan 3 - Function dan Operasi Aritmetika
Melakukan operasi penjumlahan, pengurangan, perkalian, pembagian, dan modulus.

### Latihan 4 - If-Else
Menentukan status kelulusan berdasarkan nilai mahasiswa.

### Latihan 5 - Switch
Menampilkan nama bilangan berdasarkan angka yang dimasukkan.

### Latihan 6 - Bilangan Genap atau Ganjil
Memeriksa bilangan melalui form HTML.

### Latihan 7 - Mengubah Warna Halaman
Mengubah warna latar halaman menggunakan tombol.

### Latihan 8 - Checkbox Menu Makanan
Menghitung total harga berdasarkan menu yang dipilih.

### Mini Project - Kalkulator Nilai Mahasiswa
Menghitung nilai akhir berdasarkan nilai tugas (30%), UTS (30%), dan UAS (40%), kemudian menentukan predikat dan status kelulusan.

## Cara Menjalankan
1. Unduh atau clone repository.
2. Buka folder proyek menggunakan Visual Studio Code.
3. Buka file `index.html` melalui browser untuk menjalankan latihan.
4. Buka `mini-project.html` untuk menjalankan kalkulator nilai mahasiswa.

## Kesimpulan
Praktikum ini membantu memahami penggunaan JavaScript untuk membuat halaman web yang interaktif, memproses input pengguna, dan memanipulasi elemen HTML.
